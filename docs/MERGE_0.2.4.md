## 发布提醒

重建本分支镜像并重建容器，保留现有环境、挂载、公告和 Redis 数据，不运行 `down -v`。
优先等对局结束后更新；旧挂载的 `/app/data`、`/app/public/assets` 等可能覆盖新镜像文件。

同步本次变化的 `data/` 到实际 Nginx 目录；当前 `srv` 部署在仓库根目录执行：

```sh
sudo bash scripts/copy-data-to-nginx.sh ./data /opt/1panel/www/sites/wei.linxia.dev/index/srv
```

复制脚本为本机未跟踪文件，其他机器须使用自己的同步方式。新增香槟炸弹原皮需从本地客户端重新提取，
同步匹配的素材/`local-assets.json` 并生成 `asset-hashes.json`；素材与生成指纹不提交。
游戏数据与素材 CDN 必须对应，按缓存策略刷新 CDN，更新独立 SW 依赖和浏览器 SW。
检查 `/healthz` 的 0.2.4 和新 build、`/metrics`、`/js/asset-cdn.js`，再手动验证对局、重连、音频及资源预载。
回滚同时恢复镜像、数据、素材清单/CDN，不能只回退代码。
